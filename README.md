# 🥁 Maelzel

A beautiful metronome with accents, time signatures, subdivisions and tap tempo.

**▶ Use it here: [https://drew-traldi.github.io/beats-and-bands/](https://drew-traldi.github.io/beats-and-bands/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
